# Участие в разработке

Спасибо за интерес к MDWF! Проект небольшой, процесс простой.

## Окружение

Windows + Rust (`stable-x86_64-pc-windows-gnu`) + MSYS2 (GTK4/libadwaita).
Полная инструкция — `README.md` (раздел «Требования к среде») и
`PROJECT_STATUS.md` §2/§13.

## Правила

1. **Сверяй API с первоисточником, не с памятью.** Ozon — локальная копия
   `docs/ozon-seller-api-reference.md`; WB — OpenAPI-спеки (зеркало
   eslazarev/wildberries-sdk). Названия разделов ЛК для пользователя —
   только по живому кабинету (дока отстаёт от UI).
2. **После правок API — живой прогон** (CLI `download` с реальным
   профилем), не только unit-тесты.
3. **Секреты — только в OS keyring.** В SQLite/логах/тестах — никогда.
4. Перед коммитом:
   ```bash
   cargo test --workspace
   cargo clippy --workspace --tests -- -D warnings
   ```
5. Коммит — одной логической правке; формат `feat|fix|docs(scope): суть`.
6. **Уроки проекта обязательны к прочтению** — `PROJECT_STATUS.md` §12
   (61 урок из реальных инцидентов; большинство багов повторяется, если
   их не знать).

## Проверка GUI

GTK4 на Windows не экспортирует accessibility-дерево, поэтому
widget-тестов нет. Методология — `scripts/gui-test/` (DPI-aware скриншот →
Windows OCR → SendInput-клик) и env-хук `MDWF_START_VIEW=<вкладка>` для
бес кликовых проверок. Подробности — уроки #51, #56, #59 в §12.

## Стиль кода

Rust 2021, `clippy::pedantic` в крейтах — новые предупреждения недопустимы.
Комментарии и UI-тексты — на русском (как весь проект).
