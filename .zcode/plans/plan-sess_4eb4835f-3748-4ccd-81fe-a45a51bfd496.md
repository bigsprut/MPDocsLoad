# План: Календарь для выбора дат во вкладке «Загрузка»

## Что делаем
Добавляем кнопки-календари рядом с существующими текстовыми полями дат. Ручной ввод остаётся.

## Технология (проверено по gtk4-rs 0.9)
- `gtk4::Calendar` — виджет календаря
  - `Calendar::new()` — создать
  - `cal.date()` → `glib::DateTime` — прочитать выбранную дату
  - `cal.select_day(&glib::DateTime)` — установить дату
  - `cal.connect_day_selected(|c| { ... })` — сигнал при выборе даты
  - `glib::DateTime` имеет метод `.format("%Y-%m-%d")` для форматирования
- `gtk4::Popover` — всплывающее окно
  - `popover.set_child(Some(&cal))` — разместить календарь
  - `popover.popup()` — показать
  - `popover.popdown()` — скрыть

## Изменения (только `crates/gui/src/views/download.rs`)

### Строка фильтров (row2, строки 171-187)

Заменить каждое поле даты на связку **Entry + Button-календарь**:

1. **«Диапазон дат» (date_from + date_to):**
   - Рядом с каждым Entry добавить `Button` с иконкой `office-calendar-symbolic` (или текст 📅)
   - При клике: создать `Popover` → поместить `Calendar` → `popup()`
   - Календарь предустановить текущим значением из Entry (если распарсится)
   - При `day-selected`: `cal.date().format("%Y-%m-%d")` → записать в Entry, закрыть popover

2. **«Месяц» (period_entry):**
   - Рядом с Entry добавить `Button` с иконкой календаря
   - При клике: тот же `Popover` + `Calendar`
   - При `day-selected`: `cal.date().format("%Y-%m")` → записать в Entry (только год+месяц), закрыть popover

### Хелпер-функция `make_date_picker`
Чтобы не дублировать код 3 раза, создать хелпер:
```rust
fn make_date_picker(entry: &Entry, date_format: &str) -> Button
```
- Создаёт кнопку с иконкой
- При клике: создаёт Popover с Calendar (предустановленным из entry.text() если валидно)
- При day-selected: форматирует дату, записывает в entry, закрывает popover
- Возвращает кнопку
